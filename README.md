# Online Oyunlar

Siteye girince oyun seçim ekranı gelir:

- **Blackjack** — 5 kişilik
- **Okey** — 4 kişilik

## Çalıştırma
```bash
npm install
npm start
```

Ana adres: `http://localhost:3000`

## Okey
Okey tarafında 4 kişilik oda, gösterge/okey taşı, taş çekme, atılan taşı alma, taş atma, sıra sistemi, kazanma kontrolü ve oda sahibi sıfırlaması bulunur.
